# AI/ML Practicals 1–15

This repository contains practical programs from the Introduction to AI/ML practical syllabus.

## Language and requirements
- Practicals 1–12: Prolog (written for SWI-Prolog)
- Practicals 13–15: Python 3 (as specified in the supplied practical syllabus)
- No third-party Python packages are required.

## How to run

### Prolog (Practicals 1–12)
1. Install SWI-Prolog from https://www.swi-prolog.org/Download.html
2. Open SWI-Prolog.
3. Load a file, for example:
   `?- consult('Practical_01_Student_Course_Knowledge_Base.pl').`
4. Enter one of the example queries written at the bottom of that file.

### Python (Practicals 13–15)
Run from a terminal in this folder:
`python Practical_13_Blocks_World.py`

Replace the filename to run Practical 14 or 15.
